# SmartCV – Hệ thống tạo CV thông minh tích hợp AI

## Giới thiệu

SmartCV là hệ thống website hỗ trợ người dùng tạo, quản lý và chia sẻ hồ sơ xin việc (CV) trực tuyến một cách nhanh chóng và hiệu quả. Hệ thống tích hợp trí tuệ nhân tạo (AI) để phân tích nội dung CV, đánh giá chất lượng và đưa ra các gợi ý cải thiện phù hợp với từng cấp độ kinh nghiệm trong lĩnh vực Công nghệ Thông tin.

---

## Tính năng chính

* Tạo và chỉnh sửa CV với nhiều template chuyên nghiệp
* Phân tích và đánh giá CV bằng AI
* Gợi ý cải thiện nội dung CV theo level (Intern → Senior)
* Chia sẻ CV online
* Xuất CV ra PDF
* Nâng cấp tài khoản qua thanh toán online
* Xác thực và bảo mật người dùng

---

## Công nghệ sử dụng

### Backend

* Spring Boot
* MySQL
* JWT Authentication

### Frontend

* Vue 3 + TypeScript
* Pinia (State Management)
* Axios

### Khác

* AI API (CV Evaluation)
* VNPay (Payment Integration)

## Cài đặt và chạy dự án

### 1. Clone project


### 2. Backend

# SmartCV – AI-Powered CV Management System

## Introduction

SmartCV is a web-based platform that helps users create, manage, and share resumes efficiently. The system integrates Artificial Intelligence (AI) to analyze CV content, evaluate its quality, and provide personalized suggestions based on experience levels in the Information Technology field.

---

## Key Features

* Create and edit CVs with professional templates
* AI-powered CV analysis and evaluation
* Personalized improvement suggestions (Intern → Senior)
* Online CV sharing
* Export CV to PDF
* Account upgrade via online payment
* Secure authentication system

---

## Tech Stack

### Backend

* Spring Boot
* MySQL
* JWT Authentication

### Frontend

* Vue 3 + TypeScript
* Pinia
* Axios

### Others

* AI API (CV Evaluation)
* VNPay (Payment Integration)
